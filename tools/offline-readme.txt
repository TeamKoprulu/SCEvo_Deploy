SC: Evolution Complete - offline package
Campaign {campaign} / SC Evo {multiplayer} (packaged {date})

Use this when the SC Evo launcher can't run. The launcher is still the
easiest way to install and update; this package is a manual alternative.

INSTALL
1. Find your StarCraft II folder: the one that contains Support64, Maps
   and Mods (for example C:\Program Files (x86)\StarCraft II).
2. Extract everything in this zip into that folder. Let it merge with the
   existing Maps and Mods folders, and replace files when asked.

PLAY
- Double-click "Play SC Evo.cmd" in the StarCraft II folder.
  (It starts Maps\SCEvo\EvoCompleteLauncher.SC2Map with StarCraft II.)

UPDATE
- Download the newest offline package and extract it the same way.

Not included: the Versus AI melee maps. They need the launcher, which
prepares each game before it starts.
