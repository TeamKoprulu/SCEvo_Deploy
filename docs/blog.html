Blog posts

A post is a markdown file in EvoSite/posts/. It stays unreleased until you add it to the post lists. The same scripts then create its page, short URL, sitemap entry, search entry and link preview.

The launcher reads the site

Released posts show in the launcher's news on their own (site post cards are filled live from postList.json), in the player's language when a translation exists. No deploy is needed unless you change the news feed itself.

Steps

  1. Write the .mdCreate posts/<post-id>.md, e.g. posts/evo-update-1_22.md. The id is the file name without .md. 
    ---
title: "Extension Update 1.22 patch notes"
short_title: "1.22"
author: "Kat"
date: "2026-11-15"
blog-image: "/assets/img/blog/blog-update-1_22.webp"
tags: "Update, Extension, Bugfixes"
url: "update-1_22"
description: "One line for search results and link previews."
---

# Update 1.22
***
Post body in markdown…

    Required: title, author, date (YYYY-MM-DD), blog-image, tags. url gives a short address: update-1_22 becomes scevo.org/update-1-22 (letters, numbers and dashes; underscores become dashes).

  2. Add the imagesCard image in assets/img/blog/, in-post images in assets/img/blogassets/, videos in assets/video/. Reference them from the site root (/assets/…). For videos, also run node scripts/build-video-posters.mjs.
  3. Hero and thumbnail (optional)Open tools/hero-editor.html through a local server to place a hero background and model. It writes the cinematic-* and thumb-* frontmatter. tools/showcase-editor.html builds {{showcase}} panels. posts/styleguide.md shows the other blocks ({{image-gallery}}, …).
  4. Preview locally 
    cd D:\SCBW\EvoSite
npx serve
    An unreleased post opens at /posts/<post-id>.html once its page exists (step 6 creates it; it can also be copied from another post).
  5. Check 
    cd D:\SCBW\SCEvo_Deploy
.\run.cmd check blog evo-update-1_22
    Missing frontmatter, images or videos that don't exist (in the post and its translations), page, lists, short URL, sitemap, link preview.
  6. Release 
    cd D:\SCBW\EvoSite
# lists, page, head, _redirects, serve.json
node scripts/build-postlist.mjs add evo-update-1_22
node scripts/build-sitemap.mjs
node scripts/build-search-index.mjs
# posts with a hero background
node scripts/build-og-images.mjs evo-update-1_22
  7. Check again and publish.\run.cmd check blog evo-update-1_22 should pass. Then push the site.

Editing a released post

  • Edit the .md, then node scripts/build-postlist.mjs (no arguments) to refresh every listed post's entry and page head from its frontmatter.
  • Changed the title or text? Also build-search-index.mjs, and build-og-images.mjs <id> if the preview shows the title.
  • To unlist a post (the page stays): node scripts/build-postlist.mjs remove <post-id>.

Translations

  • posts/<post-id>.<locale>.md with locale esES, koKR, zhCN, itIT or ruRU.
  • A translation inherits every frontmatter field it leaves out from the English post. Only write what's translated (title, short_title, description, …). node scripts/clean-translations.mjs trims copied fields.
  • Tags stay English: they are filter keys, and the pages translate them.
  • build-postlist.mjs writes the per-language lists (postList.<locale>.json).

Descriptions

The one-line description in search results and embeds lives in three places that must agree. Edit them together in docs/meta-descriptions.md:

# (re)build the doc from the pages
node scripts/meta-descriptions.mjs --init
# write it into the pages and postList.json
node scripts/meta-descriptions.mjs --apply
