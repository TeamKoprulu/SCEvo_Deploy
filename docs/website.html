Website push

scevo.org is a static site: no build step on the server. The scripts in EvoSite/scripts/ write their results into the repo, you commit them, and Netlify serves what's on main.

RepoD:\SCBW\EvoSite (GitHub Ailoso/EvoSite)
BranchesWork happens on whichever branch is relevant at the time; Netlify publishes main
HostingNetlify: _redirects (short URLs, written by build-postlist.mjs) and _headers (caching)
Local previewnpx serve in the repo; serve.json mirrors the short URLs

Steps

  1. Work on a branchWhichever branch is relevant for the change. Nothing is live until it reaches main.
  2. Run the scripts your change needsSee the table below. Most write files you then commit.
  3. Preview 
    cd D:\SCBW\EvoSite
npx serve
  4. Check 
    cd D:\SCBW\SCEvo_Deploy
.\run.cmd check site
    Uncommitted files, data files that don't parse, broken /assets links on every page, the download page's launcher version, and every released post.
  5. Merge and pushMerge into main and push. Netlify publishes it.
  6. Look at it liveOpen the changed pages on scevo.org. For a new post, paste its link in Discord to see the preview.

Which script after which change

You changedRun
A post's frontmatter, or released a postnode scripts/build-postlist.mjs (add <id> to release)
Added or removed a page or postnode scripts/build-sitemap.mjs, node scripts/normalize-head.mjs
Post or page textnode scripts/build-search-index.mjs
A hero background, or a page's thumbnailnode scripts/build-og-images.mjs [post-id | page-name]
templates/header.html, footer.html, mobile-menu.htmlnode scripts/inline-templates.mjs (copies them into every page)
The page shell (stylesheets, scripts, loader)node scripts/apply-page-shell.mjs
Page descriptionsEdit docs/meta-descriptions.md, then node scripts/meta-descriptions.mjs --apply
Videos in assets/video/node scripts/build-video-posters.mjs
A launcher release (if not deployed with --update-site)node scripts/sync-launcher-info.mjs
The site iconnode scripts/build-icons.mjs

Files other tools write

assets/js/site-links.js (launcher download links)Launcher deploy with --update-site

The deploy tool edits these in place and never commits; commit and push them yourself.

Notes

  • docs/ in EvoSite has the site's own notes: search index, performance work, translations still needed, meta descriptions.
  • The launcher's episode art comes from the site: after changing an episode, run npm run sync:episodes in the launcher repo and rebuild it.
