Asset splitting

On Battle.net, the art in SCEvo_Assets.SC2Mod doesn't go up as one mod. It goes out as five smaller split mods. Prepare-Upload.ps1 keeps those five in step with the dev mod and tells you which mods and maps changed since the last release.

RepoD:\SCBW\SCEvo_AssetUploads (GitHub TeamKoprulu/SCEvo_AssetUploads)
Split modsOnline Mods\: SCEvo_ProtossAssets, SCEvo_TerranAssets, SCEvo_ZergAssets, SCEvo_OnlineAssets, SCEvo_LocalizedAssets (all .SC2Mod)
SourceD:\SCBW\SCEvoDev\SC Evo Complete\SCEvo_Assets.SC2Mod
Routing decisionsasset-routing.json
Never upload SCEvo_Assets directly

Its contents reach Battle.net only through the five split mods. SCEvo_MultiArtAssets is the exception: it is uploaded straight from the dev repo. The _KR mods and Multi\ are ignored by the script.

Steps

  1. Commit the dev workIn SCEvoDev. The report counts uncommitted changes as changed too, and the check warns about them.
  2. Dry run 
    cd D:\SCBW\SCEvo_AssetUploads
powershell -ExecutionPolicy Bypass -File .\Prepare-Upload.ps1
# save the report:  -ReportPath report.md
  3. Resolve anything it can't place

    Section 2 ends with a JSON snippet for unresolved new files and for files that sit in more than one split mod. Paste it into routes in asset-routing.json and replace each "?" with Protoss, Terran, Zerg, Online or Localized. Decisions are kept for later patches.

  4. Apply 
    powershell -ExecutionPolicy Bypass -File .\Prepare-Upload.ps1 -Apply
    New and changed files are copied, files gone from dev are deleted, duplicates with a routing decision are reduced to one copy. Only the five split mods are touched.
  5. Check again 
    cd D:\SCBW\SCEvo_Deploy
.\run.cmd check assets
    It should report the split mods in sync and nothing unresolved. Review git status in SCEvo_AssetUploads and commit.
  6. Publish to Battle.netFrom the SC2 Editor, publish every mod in the report's upload list: section 1 (mods and maps changed since the last tag) plus each split mod marked needs upload. The check prints the same list as INFO.
  7. Tag the releaseTag SCEvoDev Update-<version>, with the version the patch notes post uses (whoever writes the post picks it). The next report compares from the newest Update-* tag.

Reading the report

Section 1: mods needing upload

Every .SC2Mod / .SC2Map in SCEvoDev with commits since the last Update-* tag (or -Since <ref>), plus uncommitted changes. SCEvo_Assets is listed with a note that it goes out through the split mods.

Section 2: split asset mods

new: 20   changed: 27   stale: 58   duplicates: 0   unresolved: 1
LineMeaning
NEWIn dev, in no split mod yet. Placed automatically, in this order: locale folder, race folder, a folder that already exists in one split mod, the models that use a texture (or the textures a model uses), the unit or building name. The rule used is shown in brackets.
CHANGEDDifferent in dev; overwritten where it already is.
DELETENo longer in dev; removed.
Unresolved / duplicatesNever guessed: decide them in asset-routing.json.

Per-mod metadata (DocumentInfo, ComponentList, version files, GameStrings) isn't asset content: each split mod keeps its own copy.
