Mod packaging

The deploy tool packages mods and maps from the SC2 install into the payload folders and writes the manifests the launcher reads. What ships is decided in one committed file: deploy-catalog.json.

cd D:\SCBW\SCEvo_Deploy
# the GUI in your browser
.\run.cmd
# the command line
.\run.cmd help

The packages

PackageManifestPayload folder (= R2 prefix)
Campaignupdate-manifest.json (public), beta-manifest.json, news-feed.jsonpayload/, betapayload/, assets/
Melee vs AImelee-manifest.jsonmeleepayload/ (maps, thumbs, decals)
Melee betamelee-beta-manifest.jsonbetameleepayload/

Steps

  1. Check 
    .\run.cmd check mods
    New sources nobody decided on, shipped sources that disappeared, and what changed since the last build.
  2. Decide on new sourcesCatalog tab, or: 
    .\run.cmd set "<source>" --package campaign --channel public
.\run.cmd ignore "<source>"
    <source> is the path inside the SC2 install, or just the file name when it's unique.
  3. BuildCatalog tab → Build campaign / Build melee, or: 
    .\run.cmd build --package campaign
.\run.cmd build --package melee
# just this file
.\run.cmd build --package campaign --only "Loomings3Legacy.SC2Map"
.\run.cmd build --package campaign --dry-run
    Only changed sources are repackaged; every other built file stays byte-identical, so players re-download only what changed. Folder sources are packed with MPQEditor; packed .SC2Map / .SC2Mod files are copied as they are.
  4. VersionsManifest tab: set the versions, the critical-update notice or the beta settings, then Write manifest.
  5. PushOn to Cloudflare push.

Channels

PackageChannels
Campaign itemspublic, beta, both, off

Moving a file between public and beta: change the channel and Build. The file moves to the right payload folder and both manifests are regenerated.

.\run.cmd promote "Loomings3Legacy.SC2Map" public

Melee maps

  • Pool: Add to pool / Remove from pool on the map cards, or .\run.cmd set "<map>" --package melee --channel public|off.
  • Opaque names: each map gets a random 10-character mapId once and ships as meleepayload/maps/<mapId>.evm with thumbs/<mapId>.png.
  • Metadata (name, players, modes, size, tileset, required mods) is read from the map. Modes come from the short description (1v1, 2v2, FFA) or the start locations; type in the card's Modes box to override.
  • Missing mods: the build warns when a map needs a mod that ships in neither package.

Player decals

  • Rebuilt by every melee build into meleepayload/decals/: one 64 px atlas per race, the Terran outline plates and decals.json.
  • Sources: a CascView extraction (D:\Casc Viewer\SC2\mods\liberty.sc2mod\base.sc2assets\assets\textures) and D:\SCBW\SC2GameData. Re-extract both after a game patch that adds decals.
  • Blank-looking decals: .\run.cmd decals lists them, .\run.cmd decals exclude Decal_Zerg_0083_01 leaves one out, include puts it back.

Melee beta (closed test)

  1. Tag the modsMelee beta on the mod's card, or .\run.cmd beta-tag "<source>" (off to untag). Tag the whole chain: tag Core and you tag Multi and Legacy with it. The Catalog and the build warn otherwise.
  2. Build.\run.cmd build --package meleebeta. Tagged mods go to betameleepayload/Mods/SC Evolution Complete Beta/ with their dependencies rewritten to the beta folder.
  3. SettingsManifest tab → Melee beta, or: 
    .\run.cmd melee-beta --on --name "Balance test" --code CODE --version 1.0 --accent "#ff6600"
    A new code locks out players who entered the old one.
  4. Deploy.\run.cmd deploy --package meleebeta.

Offline package

For players who can't use the launcher: Deploy tab → Build offline .zip, or .\run.cmd offline-zip. It contains only what is published in the live update-manifest.json (checked by hash), so deploy first. Writes offline\SCEvo_Offline_Campaign-<campaign>_Evo-<version>.zip; nothing is uploaded.

What a build guarantees

  • Payload folders mirror the catalog: files no item claims are removed.
  • Manifests are always regenerated, and only rewritten when their content changes. The previous version goes to manifests/.history/ (not committed, never uploaded).
